一个看板管所有 coding agent

Agent Kanban 把 Claude Code、GitHub Copilot CLI 和 Antigravity 当作看板上的任务来运行。每个任务在自己的 git 分支上工作；agent 会先做计划、互相审查、向你提问，每个 agent 的进度、token 用量和套餐额度都在一个地方看清楚。

功能

少在终端之间来回切，多交付几个任务。

  • 任务就是对话

    开一个任务，之后直接回复它提修改意见：agent 会在同一个会话里接着上次的地方继续。

  • 每个任务一个分支

    每个任务在自己的 worktree 里、kanban/<id>-<title> 分支上工作。每一轮以一次 commit 结束；看完 diff，准备好了再点 Merge。

  • 先计划

    任务可以从一轮只读的计划开始。计划等你确认或修改后，才会动代码。

  • AI 审查

    让另一个 agent 审查计划或完成的改动。任务的 agent 修改，循环直到审查通过或你设定的轮数用完。最终决定权在你。

  • agent 之间协作

    内置的本地 MCP 服务器让 agent 可以向你提问、给其他 agent 创建任务、读取看板。

  • 用量一目了然

    按任务、按 agent 统计 token 和费用，还有每个 agent 的套餐窗口（Claude 的 5 小时和每周限额、Copilot 的 premium requests 等）以及重置时间。

  • 排队

    设定同时运行几个 agent，其余的排队等候。

  • 自动领取

    打开 Auto，空闲的 agent 按先来先得领取 To Do 任务；指定给任意 agent 的任务交给剩余额度最多的那个。

  • 看板外的会话

    你在终端里运行的 Claude Code、Codex 和 Antigravity 会话也会出现在看板上（只读），并显示 token 用量。

任务流程

从想法到合并，全在一个看板上。

  1. To Do

    已创建、未开始；或在 Auto 模式下等待空闲的 agent。

  2. Running

    agent 正在任务自己的 worktree 里工作，或在排队（Queued）等空位。

  3. Confirm

    一份计划或 agent 的提问在等你回复。

  4. Review

    这一轮做完了：回复、请 AI 审查、合并，或转交给别的 agent。

  5. Done

    完成。看板外的会话空闲两小时后会移到这里。

开启 Plan first 时：To Do → Running（计划）→ Confirm → Running → Review → Done

本地优先

一切都在你自己的电脑上运行。

  • 无需 key、账号或服务器

    它使用你已经登录的 agent CLI，现有的订阅直接就能用。

  • 本地 MCP 服务器

    只监听 127.0.0.1，每一轮都有自己的 URL，这一轮结束后即失效。

  • 看板数据只属于你

    看板和 worktree 保存在你的 Application Support 目录里。删除任务会保留它在仓库里的分支。

注意：agent 以无头模式运行，并关闭了权限确认，工作范围在任务的 worktree 内。只让它们处理你信得过的代码。计划和审查轮次是只读的。

开始使用

一分钟跑起来。

安装应用

  1. 下载 DMG：一个通用版应用，同时支持 Apple Silicon 和 Intel 芯片的 Mac，需要 macOS 12 或更新版本。
  2. 打开 DMG，把 Agent Kanban 拖进“应用程序”文件夹。
  3. 从“应用程序”、Dock 或 Spotlight 打开。应用已签名并经过 Apple 公证。

你仍然需要 git，以及至少一个上面列出的 agent CLI（已安装并登录）。不需要安装 Go。

或者从源码构建

需要 macOS、Go 1.27.3 或更新版本、git，以及至少一个上面列出的 agent CLI（已安装并登录）。

从源码运行
git clone https://github.com/lzhgus/agent-kanban.git
cd agent-kanban
go run .

点 New task，描述要做什么，选择 agent 和文件夹，然后点 Add & Run。勾选 Plan first 可以在 agent 改动任何东西之前先审阅计划。

构建应用
go run github.com/egoist/mygo/cmd/mygo build -skip-dmg
cp -R "build/darwin-arm64/Agent Kanban.app" /Applications/

放进“应用程序”文件夹后，就能从 Dock 或 Spotlight 打开。应用和 go run . 共用同一个看板。Linux 应该可以运行但未经测试；暂不支持 Windows。
