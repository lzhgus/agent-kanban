One board for all your coding agents

Agent Kanban runs Claude Code, GitHub Copilot CLI, Antigravity, Grok Build, Pi, Kimi Code and OpenCode as tasks on a kanban board. Each task gets its own git branch. Agents plan, review each other and ask you questions, and you see every agent's progress, tokens and plan quota in one place.

What it does

Less terminal juggling. More shipped tasks.

  • Tasks are conversations

    Start a task, then reply to ask for changes. The agent picks up where it stopped, in the same session. Claude Code, Grok Build and Pi take your message while they work.

  • A branch per task

    Every task works in its own worktree on a kanban/<id>-<title> branch. Each turn ends in a commit; review the diff, then Merge or Open PR. New worktrees get your .env files and run your setup script.

  • Plan first

    Start with a read-only planning turn. The plan waits for you to confirm or revise it before any code changes.

  • AI review

    Have another agent review a plan or finished changes. The loop runs until the reviewer approves or your rounds run out. The decision stays yours.

  • Agents work together

    A built-in local MCP server lets agents ask you a question, file tasks for other agents and read the board.

  • Usage at a glance

    Tokens and cost per task and per agent, plus each agent's plan windows (Claude's 5-hour and weekly limits, Copilot's premium requests, Grok's weekly quota) and when they reset.

  • Queue

    Choose how many agents run at once. The rest wait their turn.

  • Auto pickup

    Turn on Auto and free agents take To Do tasks first come, first served. A task for any agent goes to the one with the most quota left.

  • Sessions outside the board

    Claude Code, Codex, Antigravity and Grok Build sessions you run in a terminal show up too, read-only, with their token usage.

How a task flows

From idea to merged, on one board.

  1. To Do

    Filed, not started, or waiting for a free agent with Auto on.

  2. Running

    An agent is working in the task's own worktree, or Queued for a free slot.

  3. Confirm

    A plan, or an agent's question, waits for you.

  4. Review

    The turn is done: reply, ask for an AI review, merge, or hand it off.

  5. Done

    Finished. Outside sessions land here after two idle hours.

With Plan first: To Do → Running (plan) → Confirm → Running → Review → Done

Local-first

Everything runs on your machine.

  • No keys, no account, no server

    It uses the agent CLIs you're already signed in to, so your existing subscriptions just work.

  • A local MCP server

    It listens on 127.0.0.1 only, and each turn gets its own URL that stops working when the turn ends.

  • Your board stays yours

    The board and worktrees live in your Application Support folder. Deleting a task keeps its branch in your repository.

Heads-up: agents run headless with their permission prompts turned off, inside the task's worktree. Only point them at code you trust them with. Planning and review turns are read-only.

Get started

Running in a minute.

Install the app

  1. Download the DMG: one universal app for Apple Silicon and Intel Macs, macOS 12 or newer.
  2. Open it and drag Agent Kanban to Applications.
  3. Open it from Applications, the Dock or Spotlight. It's signed and notarized by Apple.

You still need git and at least one of the agent CLIs above, installed and signed in. No Go required.

Or build from source

You need macOS, Go 1.27.3 or newer, git, and at least one of the agent CLIs above, installed and signed in.

Run from source
git clone https://github.com/lzhgus/agent-kanban.git
cd agent-kanban
go run .

Click New task, describe what to do, pick an agent and a folder, and press Add & Run. Tick Plan first to review a plan before the agent changes anything.

Build the app
go run github.com/egoist/mygo/cmd/mygo build -skip-dmg
cp -R "build/darwin-arm64/Agent Kanban.app" /Applications/

Keep it in Applications and open it from the Dock or Spotlight. The app and go run . share the same board. Linux should work but is untested; Windows isn't supported yet.
